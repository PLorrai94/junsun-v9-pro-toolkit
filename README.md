# Junsun V9 Pro Toolkit

Repository per analisi, documentazione e ottimizzazione **conservativa** di autoradio Android Junsun V9 Pro tramite ADB.

> Stato iniziale: **nessuna modifica allo stereo**. Prima raccolta di informazioni in sola lettura; ogni modifica futura richiede verifica e approvazione.

Il progetto privilegia strumenti open source **specifici per autoradio Android** e non intende riscrivere un debloater esistente.

La roadmap e la documentazione iniziale saranno proposte tramite pull request.

**Privacy:** non pubblicare log ADB grezzi, identificativi di dispositivo, SSID, MAC, contatti o dati di posizione.
